Add plugin-bhairab: a pre-trade token risk scanner. Exposes a `bhairab_scan_token_risk` tool that returns a proceed/caution/stop verdict for a Solana token from live market signals and on-chain authority checks — catching freeze-authority honeypots and mint-authority rug risk. Works without an API key.
